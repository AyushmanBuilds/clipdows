# ClipDows

**ClipDows — A lightweight, fast, and modern clipboard manager for Windows.**

Save, search, organize, and instantly reuse your clipboard history with a global hotkey.

## Features

* 📋 Clipboard history
* 🔎 Instant search
* 📌 Pin important items
* ⌨️ Global hotkey
* ⚡ Lightweight and fast
* 🌗 Light & dark mode
* 🖥️ Designed for Windows
* 🔐 Privacy-focused clipboard management

## Project Status

🚧 ClipDows is currently under active development.
